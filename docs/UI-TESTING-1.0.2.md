# Проверка интерфейса и приложения 1.0.2

Версия 1.0.2, versionCode 3. После сообщения о нечитаемом интерфейсе выполнены переработка экрана, измерение разметки, рендеринг и повторная проверка логики приложения.

**Результат:** 79 тестовых запусков прошли. Разметка проверена на четырёх логических размерах, со шрифтом до 200%, с закрытыми и раскрытыми разделами. Получены и просмотрены PNG-рендеры Android Native/Skia. На физическом Xiaomi эти проверки не выполнялись, точная модель и версия Android из последнего сообщения пользователя не подтверждены. Рендеры не являются фотографиями или скриншотами реального телефона.

## Изменения интерфейса

- Цвета текста, кнопок, фона и переключателей заданы явно, чтобы основные элементы не зависели от цветов системной темы. Контраст текста в проверяемых состояниях не ниже 4.5:1.
- Длинные подписи отделены от Switch и CheckBox. При системном масштабе шрифта от 130% подпись и элемент управления располагаются вертикально; шрифт пользователя не уменьшается.
- Кнопки многострочные, имеют высоту по содержимому и область нажатия от 48 dp. Основной экран прокручивается до последнего элемента.
- Системные отступы применяются явно через WindowInsets API, доступный на API 25. Повторное применение не накапливает padding. При прокрутке содержимое обрезается до безопасной области, не попадая под системные панели.
- На Android 10+ отключена автоматическая Force Dark для фиксированной светлой палитры; настройка находится в ресурсах `values-v29`, Android 7 её не читает.
- Диагностика и инструкция MIUI раскрываются кнопками на главном экране. Их состояние сохраняется при пересоздании Activity.
- Нажатие на подпись тоже переключает соответствующую настройку. При возвращении в Activity значения элементов заново синхронизируются с сохранёнными настройками.
- Неполная запись другой службы в списке Accessibility больше не приводит к исключению при формировании статуса.
- Вверху отображается версия установленного APK. Для этой сборки ожидается **«Версия 1.0.2»**.

**Итого: 79 запусков JUnit/Robolectric, 0 ошибок.** Наборы на API 25 используют legacy-графику Robolectric для измерения структуры. Проверка действительных метрик текста и PNG-отрисовка выполнены отдельно на API 35 с Native/Skia. Нельзя называть эти рендеры проверкой пикселей MIUI 10.

Матрица экранов: **320×480, 360×640, 480×320 и 411×731 dp**, масштаб шрифта **100%, 130%, 200%**. В каждом случае проверены закрытые и раскрытые разделы. Получается 24 состояния для API 25 legacy, 24 для API 35 legacy и 24 для API 35 Native: **72 состояния разметки** внутри тестовых запусков.

Проверяются положительные размеры, отсутствие перекрытия соседних строк и переключателей, выходов за горизонтальные границы, эллипсиса и обрезки текста, достаточный контраст и достижимость последнего элемента прокруткой. Пиксельная проверка системных отступов имеет отрицательный контроль: при отключении `clipToPadding` тест обязан обнаружить содержимое в зарезервированной области.

## Проверка на телефоне

После установки проверьте строку версии 1.0.2, видимость текста, прокрутку, открытие/закрытие диагностики и инструкции, оба переключателя и кнопку специальных возможностей. Повторите со штатным и увеличенным шрифтом телефона, в портретной и альбомной ориентации. После этого выполните [приёмку AnyDesk на Xiaomi](XIAOMI-CHECKLIST.md).

Функциональность с выключенным экраном, после перезагрузки и в конкретной прошивке MIUI остаётся неподтверждённой. Автоматические проверки интерфейса не заменяют эти испытания.
