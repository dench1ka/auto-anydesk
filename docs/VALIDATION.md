# Отчёт о реализации и проверках

Исторический отчёт для 1.0.0. Текущая версия 1.0.1, расширенные тесты и расследование зависания установки описаны в [AUDIT-1.0.1.md](AUDIT-1.0.1.md).

Дата: 19 ноября 2026. Версия 1.0.0, applicationId `ru.denis.anydeskconfirm`, minSdk 25, targetSdk/compileSdk 35.

## Результат

Реализован самостоятельный проект с нативным русским интерфейсом, AccessibilityService, строгим распознаванием, ACTION_CLICK, необязательной галочкой, ограничением повторов, постоянными настройками и локальной диагностикой. Основные файлы и алгоритм описаны в [README](../README.md).

**APK собран, но функциональная приёмка на физическом Xiaomi ещё не выполнена.** Сценарии захвата экрана через AnyDesk 9.1.0, погашенного экрана, MIUI 10 и перезагрузки в этой среде не проверены. Наличие APK и зелёных тестов не означает подтверждённой работоспособности на телефоне.

Использованы доступные локальные инструменты; кеш зависимостей скопирован в этот проект. Доступ к сети из shell отсутствовал. Для анализа API SDK скопирован в `.tools/android-sdk`, чтобы Lint мог записать свой кеш, не затрагивая установку другого проекта. Источники Boiler Watch, его настройки, данные и сборки не менялись.

Fallback не заменяет инструменты имитациями и не патчит ограничения среды: вызывает `aapt2`, `javac`, официальный Kotlin compiler, D8, `zipalign`, `keytool`, `apksigner` напрямую без daemon. Manifest для этого пути получает applicationId/version/minSdk/targetSdk/debuggable, которые обычно добавляет AGP. Для D8 взята версия из AGP: поставляемый в Build Tools 35 D8 старее и выдавал предупреждения о метаданных Kotlin 2.1. После выбора совместимой версии этих предупреждений нет.

Предупреждение Lint `DataExtractionRules` относится к дополнительным правилам резервного копирования на Android 12+. Для целевого API 25 установлен `allowBackup=false`; данные не резервируются штатным механизмом Android 7. Ошибок `NewApi` не найдено. Это standalone-анализ исходников, ресурсов и сгенерированного manifest, **не** успешный запуск Gradle `lintDebug`.

APK: [`../artifacts/AnyDeskAutoConfirm-1.0.0-debug.apk`](../artifacts/AnyDeskAutoConfirm-1.0.0-debug.apk), около 725 КиБ. Точная текущая контрольная сумма находится в [SHA-256 файле](../artifacts/AnyDeskAutoConfirm-1.0.0-debug.apk.sha256). Сертификат отладочный, отдельный от Boiler Watch; APK предназначен для личной установки, не для публикации в магазине.

## Автоматические тесты

**36 тестов прошли, 0 ошибок.** Запуск через JUnit 4.13.2 и Robolectric 4.14.1, Android SDK 25. Для ресурсов Robolectric использует также кешированный SDK 35 из-за targetSdk 35. Системный MediaProjection и MIUI эти тесты не эмулируют.

| Набор | Количество | Проверяется |
|---|---:|---|
| `DialogSafetyTest` | 24 | Русский и английский шаблоны, регистр/пробелы, неправильный пакет и имя, чужие/неизвестные сообщения, неправильная/неоднозначная кнопка, невидимый текст, смешанные окна/пакеты, неполное дерево, отсутствие checkbox, выключенная функция, недоступная кнопка, false/исключение API, сохранение установленной галочки |
| `AttemptLimiterTest` | 5 | Всплеск 10 000 событий после успеха, отсутствие повторного включения по таймауту, три попытки, пауза 700 мс, новое окно, общий интервал, выключенная функция, срок восемь секунд, однократная попытка checkbox |
| `AndroidConfigurationTest` | 3 | Безопасные значения настроек, сохранение через повторное создание repository, счётчик/диагностика, защищённая регистрация службы, отсутствие разрешений, создание MainActivity на API 25 |
| `WindowCaptureTest` | 4 | Чтение синтетического Accessibility-дерева, именно ACTION_CLICK, отказ для устаревшего узла, сверка текста снимка с актуальной целью, ограничение большого дерева |

Два теста `DeviceConfigurationTest` подготовлены для настоящего Android: регистрация/защита службы и отсутствие разрешений; настройки SharedPreferences. Их исходники компилируются. Для запуска в обычном окружении: `./gradlew connectedDebugAndroidTest`.

ADB тоже не смог запустить локальный сервер: `could not install *smartsocket* listener: Operation not permitted`. Поэтому инструментальные тесты не выполнялись и установка на эмулятор не подтверждена, несмотря на доступный образ API 25. Запускать повторные бессмысленные попытки при той же причине не стали.

## Что осталось подтвердить на Xiaomi

Полный [чек-лист](XIAOMI-CHECKLIST.md) включает установку и ручное включение службы, реальный диалог AnyDesk, повторные подключения без MainActivity, отсутствие действий в чужих диалогах, checkbox, выключенный экран, долгий простой, восстановление процесса/сети, перезагрузку, AD1 и одновременную работу Boiler Watch.

Нельзя подтвердить ни многомесячную доступность, ни запуск до первого разблокирования, ни сохранение Accessibility после вмешательства MIUI без такого испытания. Служба не имеет привилегий для повторного самовключения, снятия блокировки или принудительного запуска системного окна. Включённый checkbox тоже не является обещанием сохранения MediaProjection-разрешения после перезагрузки.

Проверка принадлежности запроса ограничена возможностями Accessibility: точное системное окно с полным шаблоном и именем AnyDesk плюс наличие нужного пакета. Проверенного UID инициатора MediaProjection этот интерфейс не даёт. Риск приложения с поддельным названием AnyDesk описан в README; это решение для заранее доверенного телефона.
