# Приёмка на физическом Xiaomi

**Статус всех пунктов: не выполнены в текущей среде.** Robolectric и проверка подписи APK не заменяют физическое устройство. Заполняет владелец до потери физического доступа. AnyDesk Auto Confirm не считается функционально принятым, пока ключевые сценарии, включая погашенный экран и перезагрузку, не пройдут на этом телефоне.

Запишите модель, сборку MIUI, способ блокировки экрана, версии AnyDesk/AD1/iPhone-клиента и SHA-256 установленного APK. Для каждого опыта запишите время, виден ли системный диалог, состояние экрана/блокировки, время обнаружения/попытки, изменение счётчика и фактическое появление изображения на iPhone. Не записывайте пароль AnyDesk и содержимое экрана.

| Проверка | Ожидаемый результат | Результат/дата |
|---|---|---|
| Первичная установка APK на Android 7.1.2 | Установка успешна, приложение открывается, автоматизация выключена | Не проверено |
| Включение Accessibility вручную | Служба включается и показывает «Активна» при наличии AnyDesk | Не проверено |
| Сохранение двух переключателей | После закрытия/повторного открытия значения сохраняются | Не проверено |
| Первое подключение с iPhone, экран включён | Запрос именно AnyDesk автоматически подтверждается, изображение появляется | Не проверено |
| Диагностика первого нажатия | Обновлены обнаружение и попытка, ACTION_CLICK принят, счётчик +1 | Не проверено |
| 5 повторных подключений без открытия помощника | Каждый новый появившийся запрос обрабатывается, соединение продолжается | Не проверено |
| Всплеск событий/тот же открытый запрос | Нет многократных успешных нажатий в одном окне | Не проверено |
| Автоматизация выключена | При появившемся запросе он остаётся без подтверждения, счётчик неизменен | Не проверено |
| Посторонний системный диалог с «НАЧАТЬ» | Автоматического нажатия нет | Не проверено |
| Запрос трансляции другого приложения | Не подтверждается; проверять на доверенном тестовом приложении с другим названием | Не проверено |
| Галочка выключена в настройках | Состояние checkbox не меняется помощником | Не проверено |
| Галочка включена, checkbox доступен | Устанавливается один раз перед подтверждением, не снимается | Не проверено |
| Checkbox уже установлен/отсутствует | Подтверждение работает без ошибок | Не проверено |
| Экран погашен, без открытия помощника | Изображение появляется на iPhone без касания телефона | Не проверено |
| Экран погашен, обычная блокировка устройства | Проверить реальную выбранную защиту; блокировка не обходится помощником | Не проверено |
| Простой 1 час, затем 24–72 часа, экран погашен | Повторное подключение без открытия помощника и физического касания | Не проверено |
| Удаление Activity из недавних без force-stop | Служба продолжает работу, если MIUI не отключает её | Не проверено |
| Восстановление обычного процесса Android | Проверить на тестовом устройстве без force-stop; разрешённая служба подключается системой | Не проверено |
| Настоящая перезагрузка, до первого разблокирования | Подключение без ручного открытия/разблокирования; иначе зафиксировать техническое ограничение | Не проверено |
| Перезагрузка, после первого разблокирования, затем экран выключен | Служба восстановлена Android; помощник открывать не требуется | Не проверено |
| Потеря и восстановление мобильного интернета | После возвращения сети AnyDesk снова доступен, запрос обрабатывается | Не проверено |
| Одновременная работа AD1 | Трансляция и управление с iPhone работают, другая служба остаётся включена | Не проверено |
| Одновременная работа Boiler Watch | Его собственные функции продолжают работать, настройки не изменены | Не проверено |
| После обновления/очистки MIUI | Проверить службу и все фоновые разрешения заново | Не проверено |
| Полное отключение помощника | После выключения Accessibility его автоматические нажатия прекращаются | Не проверено |

При установленной галочке система может перестать показывать новые запросы: отмечайте «диалог отсутствовал», а не приписывайте помощнику новые нажатия. Погашенный экран и заблокированный экран — разные условия; проверяйте оба.

Если тест после перезагрузки требует PIN/пароль или ручное включение Accessibility, сценарий работы без физического доступа после загрузки **не пройден**, даже если после ручного действия всё заработало. Если запрос не виден при выключенном экране либо Android не предоставляет его дерево, помощник не может надёжно решить это без изменения условий эксплуатации/привилегий. Эти результаты нельзя скрывать за успешным тестом при включённом экране.
